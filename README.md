# Microoven – Microcontroller Project

## Project Overview
Developed a microcontroller-based Microoven application as part of the Microcontroller (MC) module at Emertxe. The project focuses on microcontroller programming, peripheral interfacing, and embedded C concepts.

## Objectives
- Understand microcontroller-based application development.
- Implement embedded C programming concepts.
- Work with microcontroller peripherals and input/output operations.
- Develop modular and structured firmware.

## Key Learnings
- Embedded C programming and modular code development.
- Microcontroller peripheral configuration.
- Input/output handling and firmware debugging.
- Building and testing embedded applications.
